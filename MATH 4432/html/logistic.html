Träna en logistisk modell

Binärt fall, $Y \in \{0, 1\}$. Följer ISLP avsnitt 4.3 och fyller i den matematik boken hoppar över.

1Modellen

Vi modellerar sannolikheten $p(x) = \Pr(Y = 1 \mid X = x)$. En linjär funktion kan hamna utanför $[0, 1]$, så den skickas genom den logistiska funktionen (ISLP ekv. 4.2):

$$p(x) = \frac{e^{\beta_0 + \beta_1 x}}{1 + e^{\beta_0 + \beta_1 x}} = \sigma(\beta_0 + \beta_1 x), \qquad \sigma(z) = \frac{1}{1 + e^{-z}}.$$

Ekvivalent är log-oddsen (logit) linjär i $x$ (ekv. 4.4):

$$\log \frac{p(x)}{1 - p(x)} = \beta_0 + \beta_1 x.$$

En enhets ökning i $x$ multiplicerar oddsen med $e^{\beta_1}$. Med flera prediktorer byts $\beta_0 + \beta_1 x$ mot $x_i^\top \beta$, där $x_i$ innehåller en etta för interceptet.

2Vad som maximeras

Varje $y_i$ är Bernoulli-fördelad med sannolikhet $p_i = \sigma(x_i^\top \beta)$. Likelihooden är (ekv. 4.5)

$$\ell(\beta) = \prod_{i:\,y_i = 1} p_i \prod_{i':\,y_{i'} = 0} (1 - p_{i'}) = \prod_{i=1}^n p_i^{\,y_i} (1 - p_i)^{1 - y_i}.$$

Logaritmera och sätt in $p_i$:

$$L(\beta) = \sum_{i=1}^n \Big[\, y_i \log p_i + (1 - y_i) \log(1 - p_i) \Big] = \sum_{i=1}^n \Big[\, y_i\, x_i^\top \beta - \log\!\big(1 + e^{x_i^\top \beta}\big) \Big]$$

I maskininlärning minimerar man $-L(\beta)/n$ och kallar det binär korsentropi eller log loss. Det är samma problem.

3Gradient och Hessian

Eftersom $\sigma'(z) = \sigma(z)(1 - \sigma(z))$ blir derivatorna enkla:

$$\nabla L(\beta) = \sum_{i=1}^n (y_i - p_i)\, x_i = X^\top (y - p),$$ $$\nabla^2 L(\beta) = -\sum_{i=1}^n p_i (1 - p_i)\, x_i x_i^\top = -X^\top W X, \qquad W = \operatorname{diag}\big(p_i (1 - p_i)\big).$$

Hessianen är negativt semidefinit, så $L$ är konkav och varje stationär punkt är ett globalt maximum. Villkoret $X^\top (y - p) = 0$ har dock ingen sluten lösning, eftersom $p$ beror icke-linjärt på $\beta$. Därför behövs iteration.

4Två sätt att träna

Gradientmetoden (standard i maskininlärning), med steglängd $\alpha$:

$$\beta^{(t+1)} = \beta^{(t)} + \alpha \cdot \tfrac{1}{n} X^\top \big(y - p^{(t)}\big).$$

Newton–Raphson (standard i statistikprogram), som även använder krökningen:

$$\beta^{(t+1)} = \beta^{(t)} + \big(X^\top W^{(t)} X\big)^{-1} X^\top \big(y - p^{(t)}\big).$$

Newton-steget kan skrivas som en viktad minsta kvadrat-lösning, därav namnet IRLS (iteratively reweighted least squares):

$$\beta^{(t+1)} = \big(X^\top W X\big)^{-1} X^\top W z, \qquad z = X \beta^{(t)} + W^{-1}(y - p).$$

Newton konvergerar på ett tiotal iterationer men kräver att ett $(p+1) \times (p+1)$-system löses varje steg. Gradientmetoden är billig per steg och skalar till stora modeller, men behöver många steg och standardiserade prediktorer.

5Koefficienter, standardfel och sannolikheter

När iterationen konvergerat är $\hat\beta$ koefficienterna. Standardfelen kommer från den inversa informationsmatrisen:

$$\widehat{\operatorname{Var}}(\hat\beta) = \big(X^\top \hat W X\big)^{-1}, \qquad z_j = \frac{\hat\beta_j}{\operatorname{SE}(\hat\beta_j)}.$$

Sannolikheten för en ny observation $x_0$ och klassificeringen:

$$\hat p(x_0) = \sigma\big(x_0^\top \hat\beta\big), \qquad \hat y = \begin{cases} 1 & \hat p(x_0) \ge 0{,}5 \\ 0 & \text{annars} \end{cases}$$

Tröskeln 0,5 motsvarar $x_0^\top \hat\beta = 0$, så beslutsgränsen är linjär i $x$.

7Minimal implementation

import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def fit_newton(X, y, tol=1e-10, max_iter=50):
    beta = np.zeros(X.shape[1])
    for _ in range(max_iter):
        p = sigmoid(X @ beta)
        W = p * (1 - p)
        step = np.linalg.solve(X.T @ (X * W[:, None]), X.T @ (y - p))
        beta += step
        if np.max(np.abs(step)) < tol:
            break
    se = np.sqrt(np.diag(np.linalg.inv(X.T @ (X * W[:, None]))))
    return beta, se

def fit_gd(X, y, alpha=1.0, tol=1e-9, max_iter=200_000):
    beta = np.zeros(X.shape[1])
    for _ in range(max_iter):
        grad = X.T @ (y - sigmoid(X @ beta)) / len(y)
        beta += alpha * grad
        if np.max(np.abs(grad)) < tol:
            break
    return beta

8Fallgropar

Perfekt separation. Om klasserna kan skiljas helt av ett hyperplan finns inget ändligt maximum: $\lVert \hat\beta \rVert \to \infty$. Regularisering löser det.

Regularisering. sklearn.linear_model.LogisticRegression lägger som standard på en $L_2$-straffterm, så dess koefficienter avviker från ren maximum likelihood om man inte stänger av den.

Skalning. Gradientmetoden på rå balance konvergerar mycket långsamt, eftersom Hessianen blir illa konditionerad. Standardisera först och räkna tillbaka koefficienterna efteråt.
