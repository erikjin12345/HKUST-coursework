Integrationsordning: $P(X \le Y \le 3)$

L3 part 1, exempel (b). $X, Y$ oberoende $\text{Exp}(1)$ med täthet $f(x,y) = e^{-(x+y)}$, $x, y \ge 0$. Samma sannolikhet räknad med $y$ innerst och med $x$ innerst, varje steg utskrivet. Siffrorna kommer från code/html_checks/integration_order_check.py.

1Området

Villkoret $X \le Y \le 3$ (och $X \ge 0$) ger triangeln

$$D = \{(x,y) : 0 \le x \le y \le 3\},$$

med hörn i $(0,0)$, $(0,3)$ och $(3,3)$: allt ovanför diagonalen $y = x$ och under $y = 3$. Samma triangel kan delas upp i strimlor på två sätt:

Regeln: den inre integralens gränser får bero på den yttre variabeln; den yttre integralen har alltid konstanta gränser. Villkoret $x \le y$ blir därför

  • en nedre gräns för $y$ ($y \ge x$) om $y$ integreras först,
  • en övre gräns för $x$ ($x \le y$) om $x$ integreras först (som i föreläsningen).

2Med $y$ innerst: $\displaystyle\int_0^3\!\int_x^3 e^{-(x+y)}\,dy\,dx$

  1. Dela upp integranden. $x$ är konstant i den inre integralen, så $e^{-x}$ kan brytas ut:

    $$\int_x^3 e^{-(x+y)}\,dy = e^{-x}\int_x^3 e^{-y}\,dy.$$

  2. Primitiv funktion. $\dfrac{d}{dy}\big(-e^{-y}\big) = e^{-y}$, så

    $$e^{-x}\int_x^3 e^{-y}\,dy = e^{-x}\Big[-e^{-y}\Big]_{y=x}^{y=3}.$$

  3. Sätt in gränserna: övre minus nedre.

    $$e^{-x}\Big[\underbrace{\big(-e^{-3}\big)}_{y=3} - \underbrace{\big(-e^{-x}\big)}_{y=x}\Big] = e^{-x}\big(-e^{-3} + e^{-x}\big).$$

    Här vänder minustecknet: $-(-e^{-x}) = +e^{-x}$.

  4. Multiplicera in $e^{-x}$.

    $$\int_x^3 e^{-(x+y)}\,dy = e^{-2x} - e^{-x-3}.$$

    Kontroll: för $0 \le x < 3$ är $2x < x+3$, så $e^{-2x} > e^{-x-3}$ och den inre integralen är positiv, som den måste vara. Vid $x = 1$: $e^{-2} - e^{-4} = 0.117020$ (numeriskt med quad: $0.117020$).

  5. Yttre integralen, term för term.

    $$\int_0^3 e^{-2x}\,dx = \Big[-\tfrac12 e^{-2x}\Big]_0^3 = -\tfrac12 e^{-6} - \big(-\tfrac12\big) = \tfrac12 - \tfrac12 e^{-6},$$ $$\int_0^3 e^{-x-3}\,dx = e^{-3}\Big[-e^{-x}\Big]_0^3 = e^{-3}\big(-e^{-3} + 1\big) = e^{-3} - e^{-6}.$$

  6. Subtrahera.

    $$P(X \le Y \le 3) = \Big(\tfrac12 - \tfrac12 e^{-6}\Big) - \Big(e^{-3} - e^{-6}\Big) = \tfrac12 - e^{-3} + \tfrac12 e^{-6} \approx 0.451452.$$

3Med $x$ innerst (föreläsningen): $\displaystyle\int_0^3\!\int_0^y e^{-(x+y)}\,dx\,dy$

  1. Inre integralen, $y$ konstant:

    $$\int_0^y e^{-(x+y)}\,dx = \Big[-e^{-(x+y)}\Big]_{x=0}^{x=y} = \underbrace{\big(-e^{-2y}\big)}_{x=y} - \underbrace{\big(-e^{-y}\big)}_{x=0} = e^{-y} - e^{-2y}.$$

  2. Yttre integralen.

    $$\int_0^3 \big(e^{-y} - e^{-2y}\big)\,dy = \Big[-e^{-y} + \tfrac12 e^{-2y}\Big]_0^3 = \Big(-e^{-3} + \tfrac12 e^{-6}\Big) - \Big(-1 + \tfrac12\Big) = \tfrac12 - e^{-3} + \tfrac12 e^{-6}.$$

Samma svar, som det måste bli: båda ordningarna summerar täthet över samma triangel.

4Varifrån $\tfrac12 e^{-6} - \tfrac12$ kommer

Det felaktiga svaret är exakt

$$\int_0^3 \big(-e^{-2x}\big)\,dx = \Big[\tfrac12 e^{-2x}\Big]_0^3 = \tfrac12 e^{-6} - \tfrac12 \approx -0.498761,$$

alltså vad man får om den inre integralen blir $-e^{-2x}$ i stället för $e^{-2x} - e^{-x-3}$. Två saker har då gått fel i steg 3 ovan:

  1. minustecknet vid nedre gränsen har inte vänts ($-e^{-2x}$ i stället för $-(-e^{-2x}) = +e^{-2x}$),
  2. termen från övre gränsen, $-e^{-x-3}$, har fallit bort (den försvinner bara om övre gränsen är $\infty$).

Negativt resultat för en sannolikhet är alltid en signal: integranden $e^{-(x+y)}$ är positiv, så varje inre integral och hela svaret måste vara positiva.
